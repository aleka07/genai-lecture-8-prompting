# Prompt Engineering — Lecture 8

Slide deck for Lecture 8 of the course "Generative AI: Technologies and Applications" (al-Farabi Kazakh National University, 2026): prompt anatomy, zero-shot, few-shot, chain-of-thought, self-consistency, structured prompts and outputs, prompt chaining and ReAct, prompt evaluation, prompt injection, and when to move to RAG or fine-tuning.

**Live deck:** https://aleka07.github.io/genai-lecture-8-prompting/

Controls: ← → or Space to move, `N` speaker notes, `F` fullscreen, `T` light/dark theme. A slide can be linked directly as `#14`. On a phone the deck turns into a scrolling reading column with the lecturer's notes inline.

Interactive parts:
- self-consistency: majority-vote accuracy computed exactly from the binomial distribution for a chosen single-path accuracy p;
- Prompt Lab: one review classified with four prompts (naive, zero-shot, few-shot, structured). Model answers are illustrative and pre-recorded, so the deck works offline and without API keys.

The whole deck is one static file, `index.html`. Fonts: Onest and IBM Plex Mono (both cover Kazakh Cyrillic).

Author: Alikhan Amirkhanov.
